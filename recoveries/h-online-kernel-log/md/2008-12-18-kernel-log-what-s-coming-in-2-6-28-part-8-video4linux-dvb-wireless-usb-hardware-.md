# Kernel Log: What's coming in 2.6.28 - Part 8: Video4Linux/DVB, (Wireless) USB, hardware monitoring, and input devices

**Terry Relph-Knight**

![Kernel log logo](../site/imgs/43/3/6/5/8/3/7/a345f5e7c547062f.jpg) More than 500 of the commits in the main development branch for 2.6.28 alter the code in the Video 4 Linux/DVB subsystem, offering several new drivers and numerous improvements ([1](http://thread.gmane.org/gmane.linux.kernel/743929), [2](http://thread.gmane.org/gmane.linux.kernel/743930), [3](http://thread.gmane.org/gmane.comp.video.video4linux/40305), [4](http://thread.gmane.org/gmane.comp.video.video4linux/40374), [5](http://thread.gmane.org/gmane.linux.kernel/755867)) – for example a [gspca driver for the ALi M5602 chip](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=c109f8168f259ea1f1ab7009c6b99dbe8ea0e2b2) and a major update for the [t613 gspca driver](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=fadc79935cdb74e744c72e25f739a4acc9efabf5). [During configuration](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=eeb00c604ad203a51a0b92e124bcc4f98ba7e2c0), it is now possible to select which of the gspca subdrivers will be compiled later. The kernel hackers [replaced the driver](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=986bd1e58b18c09b753f797df19251804bfe3e84) for the Terratec Cinergy T2 . Also new is the support for the [cx24116](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=0d46748c3f874defbbbf98bcf40c7b18964abbc0), [si21xx](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=04ad28c9916da709f38b1d43817892142c2c3508), and [stv0288](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=e4aab64cb78a42e45e1d387f272712e06cf89a66) DVB-S2 chips; the cx88 and dw2102 drivers were improved to include DVB-S2 support.

[Numerous large patches](http://thread.gmane.org/gmane.linux.kernel/747670) to support [Ultra Wide Band technology](http://en.wikipedia.org/wiki/Ultra-wideband) (UWB) and [Wireless USB](http://en.wikipedia.org/wiki/Wireless_USB), which is based on this technology, were among the things incorporated into the kernel via the USB subsystem maintainers:

New are also [the fsl_qe_udc driver](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=3948f0e0c999a6201e9898bb8fbe3c6cc1199276) for the Freescale QE/CPM USB device controller and a [USB test and measurement class driver](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=5b775f672cc993ba9dba5626811ab1f2ac42883b) for devices that comply with the USB.org specification for "USB Test and Measurement devices".

[Major changes](http://thread.gmane.org/gmane.linux.kernel/742340) to the HID (Human Input Devices) subsystem code were made to simplify the future maintenance of this subsystem. Linux 2.6.28 will offer a [special driver](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=2a0bd75e5e687a9c34921e942c18477ea7ec2d63) for Elantech touchpads, which are incorporated in many Asus Eee PCs. Together with the current version of the Synaptics driver, this new driver will allow extended touchpad gestures ([documentation](http://git.kernel.org/?p=linux/kernel/git/torvalds/linux-2.6.git;a=blob;f=Documentation/input/elantech.txt;hb=HEAD)). Another new feature of 2.6.28 is the [adt7462](http://git.kernel.org/git/?p=linux/kernel/git/torvalds/linux-2.6.git;a=commit;h=c0b4e3ab0c769913438aeb078535ff117eeba5fb) driver for the ADT7462 hardware monitoring chip by Analog Devices; the kernel's hwmon subsystem, however, [still doesn't have](http://thread.gmane.org/gmane.linux.kernel/745861) an official maintainer.
